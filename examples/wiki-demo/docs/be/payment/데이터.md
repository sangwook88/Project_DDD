# 결제 데이터 (M)

결제 도메인이 단독 소유하는 테이블과 enum.

## 결제 테이블

| 필드 | 타입 | 의미 |
| --- | --- | --- |
| id | string | 결제 식별자 |
| orderId | string | 연결된 주문 식별자 |
| amount | number | 승인 금액(원) |
| status | PaymentStatus | 현재 결제 상태 |
| approvedAt | datetime | 승인 시각 |

## enum

- `PENDING` — 승인 대기
- `APPROVED` — 승인 완료
- `DECLINED` — 승인 거절
