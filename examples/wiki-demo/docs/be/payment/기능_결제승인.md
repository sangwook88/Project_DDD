# 기능: 결제승인 (C)

주문 금액을 PG로 승인하고, 승인 성공 시 등급 산정을 호출한다.

## 입력
- orderId: string — 승인할 주문 식별자
- amount: number — 승인 금액(원)

## 처리
- PG 게이트웨이로 승인 요청을 보낸다.
- 응답이 성공이면 결제 status를 `APPROVED`로 전이한다.
- 승인 직후 be/grade 등급산정을 호출한다.

## 출력·변경
- 결제 레코드 1건 생성(status=`APPROVED`).
- 반환: { paymentId, status }

## 예외·경계
- PG 거절 시 status=`DECLINED`, 등급 산정 호출하지 않음.
- 금액이 0 이하면 거부.
