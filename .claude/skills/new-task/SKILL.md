# New Task

Notion **Task 칸반보드(작업 현황)** 에 태스크 카드를 **분석 → 예시 제시 → 확인 → 생성** 순서로 만든다.
플랫폼은 Notion, 도구는 [`tools/notion/notion.py`](../../../tools/notion/notion.py)(REST) 다. 신규 카드는 기본 **시작 전** 컬럼에 놓는다.
GitHub 버그는 [new-issue](../new-issue/SKILL.md), 이건 **작업 현황 칸반** 담당이다.
**확인을 받기 전에는 절대 카드를 생성하지 않는다.**

**이 스킬을 수행하는 동안 사용자에게 보내는 모든 응답·확인 질문·보고는 한글로 작성한다.** (카드 제목·본문도 한글)

## 0. 전제 확인

- 실행 위치는 `tools/notion/`. `python notion.py ...` 로 부른다.
- `.env`(notion.py 옆)에 `NOTION_TOKEN` + `NOTION_KANBAN_DB_ID` 가 있어야 한다.
  - `NOTION_KANBAN_DB_ID` 가 없으면 카드 생성 전에 막힌다 → 사용자에게 칸반 보드 URL 을 받아
    `python notion.py kanban-info --url "<URL>"` 로 32-hex id 와 상태 컬럼(시작 전/진행 중/완료)을 확인하고
    `.env` 에 넣도록 안내한 뒤 멈춘다. 임의로 지어내지 않는다.
- 상태 컬럼명이 시작 전/진행 중/완료와 다르면 `kanban-info` 출력의 실제 옵션명을 쓴다.

## 1. 무엇을 카드로 만들지 정한다

- **인자가 있으면** 그 내용을, **없으면** 현재 대화를 분석해 무엇을 태스크로 낼지 뽑는다.
  여러 개면 후보를 나열하고 무엇을(또는 몇 개로 나눌지) 짧게 확인한다.
- **외부에서 넘어온 태스크 묶음**(예: meeting-summary 가 만든 `tasks.json` 의 `groups`)을 받았다면
  묶음 1개 = 카드 1장으로 옮긴다. 담당·상태·근거는 **넘겨준 판정 그대로** — 다시 짓지 않는다.

## 2. 카드 초안 만들기

각 카드는 **제목(한 줄) + 본문(아래 목차)** 이다. 정보가 없으면 빈 칸으로 두지 말고 `(미상)` 또는 확인 요청.

### 본문 목차 (태스크 카드)

```markdown
## 할 일 (What)
무엇을 하는지 한두 줄

## 세부 (Details)
- ...
- ...

## 도메인·트랙
도메인: <도메인명> · 트랙: 기획(피처) | 구현 | 버그 | 미정

## 담당
[담당자] (미정이면 "미정")

## 근거 (Basis)
결정/발언 등 출처 — 있으면 링크
```

- **상태**: 신규는 `시작 전`. 이미 끝났다고 보고된 일은 `완료` 카드로 이력만 남긴다(칸반 Done).
  한 묶음이 할 일/완료가 섞이면 세부별로 카드를 가른다.
- **근거 딥링크**: 근거가 소스 문서 블록 딥링크(`<문서 URL>#<블록ID>`)면 그대로 카드 근거 링크로 옮긴다
  (`--basis-url`/`--basis-label`).

## 3. 예시 제시 (게이트)

생성 전에 아래를 그대로 보여주고 확인을 받는다:

- **보드**: 작업 현황(칸반) · 대상 컬럼(예: 시작 전)
- **카드들**: 각 제목 + 본문(위 목차) + 담당/상태/근거
- 실제 실행할 명령도 함께:
  ```
  python notion.py create-card "<제목>" --body-file body.md --status "시작 전" [--basis-url <u> --basis-label <l>]
  # 여러 장이면 배치:
  python notion.py create-cards cards.json
  ```

확인 질문: **"이 내용으로 칸반에 카드를 만들까요? 고칠 부분 있으면 알려주세요."**
수정 요청이면 예시를 갱신해 다시 확인. **OK 받기 전엔 생성하지 않는다.**

## 4. 생성

확인 후에만 실행한다. 본문·다건은 임시 파일로:

- **1장**: 본문을 임시 md 로 써서 `create-card "<제목>" --body-file <f> --status <컬럼>`.
- **여러 장**: `cards.json` 을 만들어 `create-cards cards.json`.
  스키마 = `{"cards":[{title, body?, status?, assignee_ids?, basis_url?, basis_label?}, ...]}` (status 기본 시작 전).
- `assignee_ids` 는 담당자의 Notion 유저 ID. 미확인이면 비운다.

생성되면 각 카드 URL 을 사용자에게 보여준다. 실패하면 로그를 그대로 보이고 멈춘다 — 추측으로 "됐다" 안 한다.

## 하지 않는 것
- 확인 전에 카드 생성 — 예시 게이트를 반드시 거친다.
- 담당·상태·근거를 임의로 지어내기 — 넘겨받은 판정/사용자 입력을 따르고, 없으면 `(미상)`.
- 상태 컬럼명 추측 — `kanban-info` 로 실제 옵션명을 확인해 쓴다.
