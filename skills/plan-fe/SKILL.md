# plan-fe — FE 도메인 명세 (기획 전단 3단계, FE 선행)

FE 도메인의 *플로우 + 표현(V)*을 끌어낸다. **sketch 목업이 있으면 그걸 공유 소스로 [plan-be](../plan-be/SKILL.md)와 짝(코스펙)** — FE 플로우·요소와 그 호출이 닿는 BE 데이터·기능을 한 패스에 같이 깐다. **없으면 FE-first** — FE를 먼저 구체화하고 요소가 부르는 기능에서 BE를 도출. 요소는 BE 기능을 **링크로만** 부른다(FE→BE 단방향). 전제: [decompose](../decompose/SKILL.md)로 HOME 확정 + (있으면) sketch 목업. 규약: [docs/conventions.md](${DDD_ROOT}/docs/conventions.md). 산출: `docs/fe/<name>/`.

## 경계 (절대 규칙)
- FE = **플로우(오케스트레이션) + 표현(V)** 만. 기능 구현 로직은 BE 도메인. 요소가 호출하는 기능은 BE 기능 **링크만**.
- 산출: `docs/fe/<name>/` 한 곳.

## 표준 구조
`README.md`(도메인폴더-README) + `플로우.md`(루트 고정·단일) + `요소/<노드>.md`(노드 1 = 파일 1) + `일지.md`.
**금지:** 플로우를 단계폴더(C/·M/·V/)에 두기 · 노드 상세를 `요소/` 밖에 흩뿌리기.

## 하드 제약
- AI는 값을 생성하지 않는다 — 빠지면 `*[입력 필요: …]*`.
- 기존 FE 폴더가 있으면 덮어쓰기 금지(점검·교정 모드 — 어긋난 곳 교정 or 요소만 추가).
- 의미 있는 변경 후 일지 항목 + 상태 갱신. `일지.md`는 읽지 않는다(write-only).

## 흐름
1. **모드 판정** — `docs/fe/<name>/` 유무. 없음=신규 골격, 있음=점검·교정(덮어쓰기 금지).
2. **맥락 살짝** — `CONTEXT.md` + HOME 참조 그래프 + 인접 FE README + **(있으면) sketch 목업**으로 진입·진출·등장 요소를 추린다. sketch가 화면·전이를 이미 보여주면 플로우 초안의 1차 근거다.
3. **플로우 브레인스토밍** — 대화로 노드/간선을 함께 그린다. 한 번에 하나씩, mermaid 초안 보여주고 확인(노드 = 요소 1개). sketch가 있으면 그 화면 흐름을 기준으로 노드를 깐다.
4. **값·구체화 브레인스토밍** — 입력 계약 · 노드 간 전이값 · 출력을 끌어낸다. **추상·모호한 문장("적절히 처리", "필요시 갱신")은 한 번에 하나씩 구체값(수치·범위·규칙·시점)을 캐묻는다.** 값은 사람이, AI는 [입력 필요]·질문만.
5. **요소·BE 도출** — 노드 목록 = 요소 목록(한국어 파일명). 각 노드가 부르는 기능을 추려, 그 호출들에서 **BE 도메인/기능을 도출**한다(HOME 참조 그래프와 대조해 갱신·신설). FE가 무엇을 부르는지가 BE 경계의 근거다.
6. **골격 생성 → BE 코스펙 인계** — `${DDD_ROOT}/templates/`의 도메인폴더-README·플로우·요소를 복사·토큰 치환(기울임 안내문 유지). step 5에서 도출한 BE를 **[plan-be](../plan-be/SKILL.md)로 명세하는 게 표준 다음 단계**다(선택 아님) — sketch가 있으면 같은 sketch를 공유 소스로 짝지어 명세.

## 산출
- `플로우.md` = mermaid + FE 전체 값. `요소/<노드>.md` = 요소 템플릿 7섹션. `README.md` 구성 = `요소/<노드>.md` 링크 목차.
- 폴더가 이미 있으면 개별 요소 파일만 신규 생성. 한국어 + 마크다운, 식별자 영문.

## 종료
생성된 FE 폴더 + 남은 슬롯 + 도출한 BE 후보 목록 + "다음 = [plan-be](../plan-be/SKILL.md)로 그 호출이 닿는 BE를 **짝으로 명세(코스펙)** → 슬롯 채운 뒤 [distill](../distill/SKILL.md)로 가지치기·정제" 안내.
