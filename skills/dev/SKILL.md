# dev — 도메인/티켓 구현 (제네릭)

배정된 계약 1개를 계약서대로 구현한다. 계약은 셋 중 하나:
- BE 도메인 폴더 `docs/be/<name>/` (데이터.md=M + 기능_*.md=C)
- FE 도메인 폴더 `docs/fe/<name>/` (플로우.md + 요소/<노드>.md=V)
- 티켓 `tickets/<be|fe>/NNNN-*.md`

계약 자체가 BE(M·C)인지 FE(플로우·V)인지 선언한다(트랙별 에이전트 없음). 규약 SoT: `docs/arch/ARCHITECTURE.md`. 공통 구현 경계: [docs/conventions.md](${DDD_ROOT}/docs/conventions.md) §구현 경계.

## 시작 전 읽기
1. 배정 계약 — 도메인 폴더면 `README.md` + (`데이터.md`+`기능_*.md` | `플로우.md`+`요소/*.md`) 전부; 티켓이면 티켓 1장.
2. `docs/arch/ARCHITECTURE.md` — §패턴 정책·데이터·영속·에러·레이어·명명.
3. 의존 도메인의 문서·코드 — **읽기만, 수정 금지.**

`일지.md`는 **읽지 않는다**(write-only 디버그 로그).

## 구현 범위 — 계약 종류에 맞춰
**BE (`데이터.md`=M / `기능_*.md`=C):**
- **M** — 소유 테이블/enum/관계. ARCHITECTURE 데이터·영속·직렬화 규약.
- **C** — 각 기능의 입력 → 처리(규칙·계산·경계) → 출력·변경 → 예외·경계. `README.md` 패턴으로: **TS**=절차적 트랜잭션 스크립트 / **DM**=규칙·불변식·상태를 모델에 응집.

**FE (`플로우.md` / `요소/*.md`=V):**
- **플로우** — 화면 전환·노드/간선(입력·조건 → 전이), 요소 `분기·다음 전이`의 모든 갈래.
- **V** — 각 요소의 `화면·연출`. ARCHITECTURE FE 레이어 매핑·명명.
- 데이터는 요소 `호출하는 기능`의 BE 기능(C)을 **호출만**(FE → BE 단방향). 데이터·스키마·enum은 만들거나 고치지 않는다.

## 절대 규칙
1. **계약대로만** — 문서에 적힌 것만. 인터페이스/시그니처가 있으면 그대로.
2. **경계 엄수** — 다른 도메인·범위 밖 파일 수정 금지. 재설계·리네이밍·겸사겸사 리팩터·새 의존 추가 금지. BE는 플로우·화면·연출(V)을, FE는 데이터·기능(M·C)을 만들지 않는다.
3. **값 생성 금지·빈 슬롯 멈춤** — `[입력 필요]` 슬롯이 남았거나 규칙·수치·전환 규칙이 모호하면 짓지 말고 멈춰 무엇이 막혔는지 보고.
4. **컨벤션** — 식별자 영문 / 주석·문서 한국어. 명명·직렬화는 ARCHITECTURE.

## 종료
변경 요약 + 수용 충족 여부 + 도메인 폴더 `일지.md` 결정 1줄(write — 의미 있는 변경 시에만). push는 하지 않는다(검토·커밋은 사람). 한국어 + 마크다운, 식별자 영문.
