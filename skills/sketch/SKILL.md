# sketch — 제품 비전 저코스트 목업 합맞추기 (brainstorm 직후, roadmap 이전)

브레인스토밍이 빚은 **거시 목표**를 **저코스트 클릭형 목업**으로 빠르게 그려, 텍스트로만 합의한 비전을 사람이 **눈으로 클릭하며** 확인한다. "AI가 그리는 것 = 내가 그리는 것"의 간극을 **decompose 전에 싸게** 닫는 것 — 사람도 이때 더 구체화·수정한다. 도메인 분할·명세는 아직 아니다([roadmap](../roadmap/SKILL.md)→[decompose](../decompose/SKILL.md)→plan 몫). 전제: [brainstorm](../brainstorm/SKILL.md) 설계 브리프. 규약: [docs/conventions.md](${DDD_ROOT}/docs/conventions.md). 산출: `docs/brainstorming/<topic>-sketch.html` + 합맞춘 수정의 **브리프 되먹임**.

## 절대 규칙
1. **저충실도로 싸게.** 핵심 경험·플로우만 와이어 수준으로 — 픽셀 정확도·완성도·전수 화면에 시간 쓰지 않는다(상세 화면은 [plan-fe](../plan-fe/SKILL.md) 몫).
2. **프로젝트 값 생성 금지.** 수치·수량·규칙·방식·계산식을 짓지 않는다 — 목업 데이터·라벨은 `[예시]`, 사람이 정할 값은 `[입력 필요]`로 노출(규약 계승). 비전 정렬 단계라 미결 노출은 OK.
3. **읽기 전용 위키.** `HOME.md`·`CONTEXT.md`·코드는 읽되, 쓰는 건 목업 HTML과 설계 브리프뿐 — **도메인 폴더(`docs/fe/*`·`docs/be/*`)는 만들지 않는다**(아직 없다).
4. **콜드 스타트로 생성.** HTML은 새 서브에이전트가 **브리프만** 입력으로 만든다(메인 스레드 컨텍스트 오염 차단). push 금지.

## 흐름
1. **브리프 수집** — `docs/brainstorming/*-brief.md`를 읽는다(없으면 brainstorm 먼저 안내). 핵심 기능 목록·대상 사용자·문제·엣지 체크리스트가 대본이다.
2. **핵심 경험 추리기** — 브리프에서 "처음부터 끝까지 한 번 겪는 핵심 여정" 1~2개를 사람과 한 줄로 합의한다(전수 아님 — 무엇을 그릴지부터 갈림길로 묻는다).
3. **저코스트 목업 생성 (콜드 서브에이전트)** — 브리프 경로 + [templates/sim.html](../../templates/sim.html)만 건네 새 에이전트를 띄운다. 합의한 핵심 여정을 **클릭으로 넘어가는 저충실 단일 HTML**(`docs/brainstorming/<topic>-sketch.html`)로:
   - 화면 = 핵심 요소만 거친 배치(와이어 수준). 데이터·텍스트·라벨은 `[예시]`, 사람이 정할 값은 `[입력 필요]`.
   - 화면 전이·선택지는 **버튼/요소**로, 브리프가 함의한 흐름만. 브리프에 없는 동작은 지어내지 않는다(없으면 "비전 미정" 표시).
4. **사람 클릭 → 합 확인** — 어긋나면 **한 번에 하나씩** 끌어낸다: 빠진 화면·여정 / 다른 흐름 / 다른 기능 모양 / 놓친 엣지. 값은 사람이, AI는 질문·슬롯만.
5. **브리프 되먹임** — 합맞춘 수정을 설계 브리프에 반영: 핵심 기능 목록 조정, 엣지 체크리스트 보강, 안 할 것(scope) 갱신. **비전이 크게 바뀌면 목업을 다시 띄워 한 번 더 돈다**(저코스트라 반복이 싸다).

## 산출
- `docs/brainstorming/<topic>-sketch.html` — 저충실 클릭형 목업. **[decompose](../decompose/SKILL.md)·코스펙의 1차 소스** — FE 플로우·화면 데이터를 보여줘 decompose가 FE·BE 경계를 firm하게 긋고, plan-fe·plan-be가 **공유 소스로 짝지어** 깐다. (저충실이라 잡히는 건 구조·경계·계약 골격 — 값은 슬롯, 목업이 닿지 않은 BE는 plan-fe 도출로 폴백.)
- 갱신된 `docs/brainstorming/<topic>-brief.md` — 합맞춘 비전(핵심 기능 목록·엣지 체크리스트·scope).

## 종료 — roadmap으로 핸드오프
합이 맞으면 목업 경로 + 브리프에 되먹인 변경 요약 + "다음 = [roadmap](../roadmap/SKILL.md)으로 버전 스코프 자르기 → [decompose](../decompose/SKILL.md)가 이 목업으로 FE·BE를 firm하게 분할" 안내. 아직 어긋나면 2~5를 더 돈다. 한국어 + 마크다운, 식별자 영문.
